# Programación II Camila-Fleitas 2026.

## Organización del repositorio

El repositorio se encuentra organizado en tres carpetas principales, correspondientes a las tres unidades del curso de Programación II (Introducción a la Programación Orientada a Objetos, Metodología de desarrollo Orientada a Objetos y Lenguaje de programación Java).

Dentro de cada carpeta se encuentran los materiales trabajados durante el curso y publicados en CREA. Estos incluyen archivos PDF con los contenidos teóricos y materiales proporcionados por el profesor.

Además, cada unidad cuenta con una carpeta denominada Ejercicios, donde se encuentran organizadas las actividades y los trabajos prácticos correspondientes a esa unidad.

Curso-JAVA: repositorio del profesor, clonado para disponer de sus materiales.
